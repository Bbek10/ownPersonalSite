Three second-hand mini PCs, one plug meter, one month. The question was simple: which of these is cheapest to leave switched on, given they cost roughly the same to buy?

Method

Each machine ran the same baseline — an idle OS, no VMs, screen off — for a week, logged at one-minute intervals. Idle is the number that matters here, because these machines spend most of their life doing nothing in particular. 

# average watts over the sample
awk '{ sum += $2; n++ } END { print sum / n }' readings.tsv

Results

  • The oldest machine drew the most, by a wide margin
  • The two newer ones landed within a watt of each other
  • The difference between best and worst, over a year, was roughly what one of the machines had cost to buy

What I changed

The thirsty one became the machine that wakes for backups and sleeps again, and the quiet one took over everything that has to be up all the time. Same hardware, a third less power, and the only work was measuring.
